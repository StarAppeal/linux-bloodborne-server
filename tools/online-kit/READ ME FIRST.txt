BLOODBORNE SEAMLESS CO-OP TEST KIT
==================================

This is a test build of seamless co-op for Bloodborne on shadPS4. One player
(the host) runs the servers; the other (the guest) only runs the game.

YOU NEED
  - Your own Bloodborne.PC.Online folder (game 01.09), the same one you
    already play with. Keep the same mods enabled as the host. Nothing in it
    gets changed.
  - The VPN you already use with the host (Radmin VPN), connected.
  - If shadps4.exe will not start ("MSVCP140.dll was not found"), install the
    Microsoft Visual C++ Redistributable x64:
    https://aka.ms/vs/17/release/vc_redist.x64.exe

STEPS (guest)
  1. Unzip the zip straight into your Bloodborne.PC.Online folder, next to
     "LAUNCH - shadPS4 Launcher.bat". You get a SeamlessCoop folder and a few
     "... Seamless Co-op" .bat files beside your old ones.
  2. In SeamlessCoop, right-click "FIREWALL - Allow (run as admin)" and run it
     as administrator.
  3. Run "SETUP - Seamless Co-op":
       Bloodborne.PC.Online folder   Enter (it finds the folder it is in)
       host or guest                 guest
       Host IP                       the host's 26.x.x.x address from Radmin VPN
       Account name / password       pick any, and tell the host so they can
                                     register it
       Party                         exactly what the host tells you
       P2P UDP port                  Enter (51611)
  4. Wait for the host to say the servers are up and your account is
     registered. Optional check: open http://HOST-IP:20443/status in a browser;
     it should say "ok": true.
  5. Run "LAUNCH - Seamless Co-op", load your character, and wait. You are pulled into the
     host's world automatically after a few seconds. No bells needed.

NOTES
  - SETUP copies your DATA\user folder (settings and saves) into this kit, so
    progress made here stays here. It also makes a "game" folder that links to
    your install's game, patch and mods and adds the co-op event files (boss
    loot, deaths, messenger gifts) on top. Your normal install is not touched.
  - When the host sends a newer kit, unzip it the same way (overwrite) and run
    "SETUP - Seamless Co-op" again (Enter keeps every answer).
  - The old "LAUNCH - shadPS4 Launcher" still starts the old version as before.
  - The emulator log is SeamlessCoop\user\log\shad_log.txt. Send it to the host if
    something goes wrong.
  - Both players must run the exact same shadps4.exe from the host's kit.
